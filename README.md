# The emission-inequality nexus across stages of development

This repo contains the data and code required to reproduce the empirical analyses presented in "The emission-inequality nexus across stages of development" by F. Lamperti, E. Palagi and T. Perniola (World Development, 2026). 

Repository contents:

rep_code_main.R: Main replication script, reproducing the main figures and tables presented in the paper.

functions_rep.R: Auxiliary functions used by rep_code_main.R to estimate the regression models.

em_ine_nexus_data.csv: Dataset used in the empirical analyses.

variables_description.txt: Description of the variables included in the dataset.
